# YouTube Year Time Machine

Firefox extension to filter YouTube search results by a specific year (2005–Present).

## Install
1. Open `about:debugging` in Firefox → **This Firefox**.
2. Click **Load Temporary Add-on...** and select `manifest.json` (or `dist/youtube-year-time-machine.zip`).

## Usage
Search on YouTube and pick a year from the toolbar above the results or via the extension icon.
