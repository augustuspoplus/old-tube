# YouTube Year Filter

Sick of the obnoxious and shit content the Youtube algorithim is force feeding down you? Or the waves of clickbait and cuckfaced thumbnails? Well hopfulley this extension  will help you out a bit. With this you can select to have all search results from youtube be from a certain paticular year, such as 2014, or 2007. And you can also have multiple selected at a time if you prefer to instead. Project is currently experimental, and we shall see where it goes.
